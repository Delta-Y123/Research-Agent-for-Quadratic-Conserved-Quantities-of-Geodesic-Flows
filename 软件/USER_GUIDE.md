# Black Hole Simulator — 使用说明

> 版本 0.1.0（B 档核心版本）· Windows x64 · 需要 NVIDIA 显卡（CUDA）

---

## 1. 启动

| 方式 | 操作 |
|---|---|
| 安装版 | 双击 `BlackHoleSimulator_Setup.exe` → 安装 → 从开始菜单或桌面快捷方式启动 |
| 免安装版 | 直接双击 `dist\BlackHoleSimulator.exe`（整个 `dist` 目录可以整体拷走） |
| 命令行渲染 | `dist\bh_cli.exe --preset shadow --width 800 --height 450 --out a.png` |

启动后状态栏会显示检测到的 GPU，例如
`CUDA: NVIDIA GeForce RTX 3050 6GB Laptop GPU (sm_86, 6.0 GB, 1492 MHz)`。
如果这里显示 “CUDA device not available”，说明驱动或显卡不可用，相机视图会退化成 CPU 渲染。

## 3. 左侧「场景设置」

### 3.1 预设场景
下拉框，选中即切换整套实验（背景参数 + 天体 + 相机 + 吸积盘）。共 8 个：

| 预设 | 内容 | 应该看到 |
|---|---|---|
| Schwarzschild 圆轨道 r = 10M | a=0，赤道圆轨道 | 轨迹是闭合圆，E、L_z 恒定 |
| Schwarzschild 椭圆轨道（进动） | 0.78 倍圆轨道速度 | 近星点逐圈进动 |
| Schwarzschild 逃逸轨道 | 局部速度 0.62c 外抛 | 轨迹飞出计算区域 |
| Schwarzschild 捕获轨道 | 近径向内落 | 穿过视界终止 |
| Kerr 倾斜轨道 a = 0.9 | 倾角 62° | 轨道面被参考系拖曳进动 |
| 光线偏折 b = 5M | 单条零测地线 | 明显弯折 |
| 平行光束（7 条） | 7 条平行光线 | 不同碰撞参数偏折不同 |
| 黑洞阴影 a = 0.9 | 相机 r≈34M、倾角 78° | 阴影 + 薄盘 + 透镜星场 |

### 3.2 黑洞质量 M / 自旋 a/M
- **M**：0.1–10，内部始终按 `M` 归一化，改它主要影响标签数值。
- **a/M**：0–0.99，0 是 Schwarzschild，越大参考系拖曳越强。
- 改完立即重算全部轨迹并重新出图。若 `a ≥ M` 会提示“a 必须小于 M”并忽略本次修改。

### 3.3 天体与光线列表
每行是 `名字 [天体/光子]`。**单击选中**后，右侧「物理与研究」标签页显示这一条的守恒量与漂移曲线。
只有被选中的那条轨迹会用加粗线绘制。

### 3.4 三个按钮
| 按钮 | 作用 |
|---|---|
| **+ 天体** | 在 r=12M 赤道面加一个按圆轨道速度运动的测试粒子 |
| **+ 光线** | 在 (-30, 0, 6) 处加一条沿 +x 方向的光子 |
| **移除** | 删除当前选中的那一条 |

### 3.5 三个复选框
| 选项 | 作用 |
|---|---|
| **显示吸积盘** | 三维视图和相机视图里的薄盘。关掉后相机视图只剩阴影 + 星场 |
| **显示参考网格** | 三维视图的 z=0 网格和红/绿/蓝三条坐标轴（x/y/z） |
| **显示轨迹** | 三维视图里的轨迹线 |

### 3.6 「重新计算轨迹」与信息区
- 按钮：强制重算所有轨迹（改完参数后一般会自动算，这里用于手动重来）。
- 信息区显示：`视界 r+`、`赤道能层 rE`、`轨迹采样点数`、`终止原因`
  （affine parameter budget exhausted / crossed the event horizon / escaped to r > ... M）。

## 4. 中间「三维轨迹视图」

| 操作 | 效果 |
|---|---|
| 左键拖动 | 绕黑洞旋转视角（方位角、俯仰角） |
| 滚轮 | 拉近 / 拉远（相机距离 3–800 M） |

画面里画了什么：

| 元素 | 外观 | 含义 |
|---|---|---|
| 视界 | 黑色球面 | `r = r+` 的坐标曲面 |
| 能层 | 紫色半透明 | `r = M + √(M²−a²cos²θ)` 的坐标曲面 |
| 吸积盘 | 橙色半透明圆环 | z=0 赤道薄盘，内缘到外缘 |
| 天体 | 小实心球 | 当前 λ 时刻的位置 |
| 轨迹 | 彩色折线 | 从 λ=0 到当前 λ 的路径 |
| 相机标记 | 蓝色小球 | 右侧相机视图的观察者位置 |
| 网格/坐标轴 | 灰线 / 红绿蓝 | 参考平面与 x/y/z 方向 |

> 这些曲面和轨迹都是**坐标表示**，不是空间的等距嵌入，画面里的“长度”不能直接当物理距离读。

## 5. 右侧「观察者相机」标签页

这里显示的是**观察者在当前位置实际会看到的画面**：每个像素反向追踪一条零测地线，
光线落入视界就是黑的，逃到远处就采样背景星场，穿过薄盘就按盘的温度和红移着色。
所以黑洞阴影的边界是算出来的，不是画上去的圆。

| 操作 | 效果 |
|---|---|
| 左键拖动 | 转动相机朝向（偏航 / 俯仰） |
| `W` / `S` | 沿视线前进 / 后退 1 M |
| `A` / `D` | 左右平移 1 M |
| `Q` / `E` | 上移 / 下移 1 M |
| 滚轮 | 改变视场角（向上变大=拉远，向下变小=放大） |

- 相机不能进入 `1.35 r+` 以内，太靠近会被拒绝。
- 左上角显示 `宽×高  耗时 ms  a=自旋`，例如 `480×270 238 ms a=0.00`。
- 改动相机后约 0.2 秒自动重绘（防抖），拖动过程中不会每帧都重算。

## 6. 右侧「物理与研究」标签页

上半部分是选中天体的守恒量初值：

| 字段 | 含义 | 期望 |
|---|---|---|
| `E` | 比能 `-p_t` | 圆轨道 r=10M 时 ≈ 0.9562 |
| `L_z` | 轴向角动量 `x p_y − y p_x` | 圆轨道 r=10M 时 ≈ 3.7796 |
| `Carter Q` | `p_θ² + cos²θ[a²(m²−E²) + L_z²/sin²θ]` | Kerr 轨道中应恒定 |
| `2H` | 归一化约束 | 有质量粒子 = −m²，光子 = 0 |

下半部分是**相对漂移曲线**（相对 λ 的归一化偏差）：橙=E，绿=L_z，蓝=Carter Q，品红=2H。
曲线越平说明积分越准；`2H` 的漂移直接反映数值误差。

底部一行给出 E / Lz / Q 的最终相对漂移、采样点数、终止原因。

> 判断标准：曲线整体平移或单调漂移 → 数值误差；突然跳变 → 事件处理或初条件有问题。

## 7. 底部播放条

| 控件 | 作用 |
|---|---|
| **▶ 播放** | 按 λ 推进，天体沿轨迹运动，轨迹逐渐画出 |
| **⏸ 暂停** | 停在当前 λ |
| **单步** | 前进 5 个 M 的 λ |
| **重置** | λ 回到 0 |
| **速度** | 1–200，默认 40（约 40 M/秒） |
| **λ / t 读数** | λ 是仿射参数，t 是该天体的坐标时间 |
| **成像质量** | 预览 480×270 / 中等 800×450 / 高清 1280×720 |

注意：播放按 **λ** 推进，不是按各自的固有时间。多个天体一起播时用的是同一个 λ 刻度。

## 9. 五分钟上手流程

1. 启动 → 默认是「Schwarzschild 圆轨道 r = 10M」。
2. 看中间：橙色圆环是吸积盘，黑色是视界，橙色圆圈是轨迹。
3. 点底部 **▶ 播放**，看天体沿轨迹跑一圈。
4. 点右侧 **观察者相机**，拖动鼠标转视角，看阴影和星场怎么被透镜扭曲。
5. 把 **自旋 a/M** 改成 0.9，看轨道面开始进动、阴影变形。
6. 切到 **物理与研究**，确认 Carter Q 的曲线是平的。
7. **文件 → 导出图像 PNG**，得到一张带阴影的图。

## 10. 常见问题

**Q：相机视图一片黑？**
A：相机可能正对着视界（阴影本来就黑），或者视场角太小。先拖动转一下，再滚轮放大视场。

**Q：轨迹看不见？**
A：检查「显示轨迹」是否勾选；另外吸积盘是不透明几何，轨迹在盘面附近时可能被挡住，关掉「显示吸积盘」试试。

**Q：改了 M 或 a 之后轨迹没变？**
A：正常情况下会自动重算；如果没变，点「重新计算轨迹」。

**Q：成像很慢？**
A：预览分辨率下约 0.2–0.3 秒一帧；高清 1280×720 约 1 秒。笔记本请插电，电池模式下 GPU 功耗受限。

**Q：能算双黑洞吗？**
A：不能。背景固定，测试天体之间没有引力相互作用，这是设计范围。

**Q：为什么画面里的“距离”感觉不对？**
A：三维视图画的是 Kerr-Schild 坐标，不是等距嵌入；只有相机视图是逐像素按零测地线算出来的。

## 11. 物理约定速查

| 项目 | 约定 |
|---|---|
| 单位 | `G = c = 1`，长度和时间以 `M` 为单位 |
| 号差 | `(-, +, +, +)` |
| 坐标 | Kerr-Schild 笛卡尔 `(t, x, y, z)`，视界处无坐标奇性 |
| 粒子 | `H = ½g^{μν}p_μ p_ν`，`2H = −m²` |
| 光子 | `H = 0` |
| CPU 积分 | Dormand–Prince 5(4) 自适应，`rtol = 1e-9` |
| GPU 积分 | 四阶 Runge–Kutta，`h ≈ 0.03(1+r)`，FP32 |
| 吸积盘 | 几何薄盘，`T ∝ r^{-3/4}`，含红移/多普勒因子 |

定量结论请以 CPU 轨迹和守恒量漂移为准，GPU 图像是“看起来对”的预览级精度。
