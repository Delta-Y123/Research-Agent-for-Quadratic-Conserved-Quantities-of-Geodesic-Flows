# 四维时空——研究内容、编程特点与研究成果

## 研究内容

第一阶段在二维模型上把流程跑通后，第二阶段把同一套方法搬到**四维广义相对论时空**，
回答两个问题：

1. **验证**：工具能否正确识别已知时空中的二次守恒量？这是对第一阶段的代码在
   球坐标、非平直联络、Lorentz 度量下的可信度检验。
2. **半自动搜索**：在人为设定的、Carter 式的基张量张成的空间里，能否**重新解出**
   Carter 张量，而不只是把已知答案代进去核对？

按规划给出的基准顺序，验证覆盖平直时空、Schwarzschild 时空与 Kerr 时空：

| 基准 | 验证的守恒量 | 用来检查什么 |
| --- | --- | --- |
| 平直空间 | $K=\eta$（$Q=2H$）；$L^2$ 张量 | 基本计算是否正确 |
| Schwarzschild 时空 | $Q=p_t^2+p_\phi^2$ ； $L^2$ 张量 | 球坐标、非平直联络、可约性处理 |
| Kerr 时空 | Carter 张量 | 能否处理真正的隐藏对称性 |

四维二阶 Killing 张量有 10 个未知分量，完整方程规模增长极快。我们**不是**
在 10 个任意函数里盲目搜索，而是把「Carter 式」的结构显式写成一个**基张量展开**

$$K^{\mu\nu}=\sum_{i=1}^{5}c_i\,T_i^{\mu\nu},$$

其中 $\{T_i\}$ 由度规、坐标基张量与 $\cos^2\theta$ 因子组合而成，$c_i$ 为待定常数。
这样「求 Killing 张量」就化为**解一个关于 $c_i$ 的齐次线性系统** $M\mathbf c=0$，
解空间维数与基底直接给出答案。

## 算法设计与实现

两个程序：`killing_tensor_verify_4d.py` 做验证，输入已知的 $g$ 与 $K$ 验证对应的$Q$是否是不变量；`killing_tensor_search_4d.py` 做半自动搜索，**并复用验证程序里的系数提取函数做独立复核**。

1. **免三角替换的 $u=\sin^2\theta$ 技巧。** Kerr 度规与 Carter 张量只依赖
   $\sin^2\theta,\cos^2\theta$，且与 $t,\phi$ 无关。令 $u=\sin^2\theta$，则

   $$\frac{\partial}{\partial\theta}f(u)=2\sin\theta\cos\theta\,\frac{\partial f}{\partial u},$$

   于是每个三次动量系数的泊松括号只可能是

   $$P(u,r)+\sin\theta\cos\theta\cdot Q(u,r),$$

   其中 $P$ 来自 $\partial_r$ 项、$Q$ 来自 $\partial_\theta$ 项（已提出 $2\sin\theta\cos\theta$）。
   由**奇偶性**（$P$ 关于 $\theta$ 为偶，$\sin\theta\cos\theta\,Q$ 为奇），

   $$\{Q,H\}=0\iff P=0\ \text{且}\ Q=0 .$$

   这一步把一个含有三角函数的零检验，拆成了两个纯有理式的零检验，**全程不需要
   `trigsimp`**，也就避开了符号三角化简常见的卡死与内存爆炸。

2. **通分取分子，逐单项式提系数。** 每个 $P,Q$ 是 $(u,r)$ 的有理式，用
   `together` + `fraction` 取分子后，按 $(u,r,M,a)$ 的单项式展开，每个单项式系数置零
   即得一条关于 $c_i$ 的线性方程。整个过程**不出现分母**，方程也不会因分母为零而丢解。

3. **符号精确，无采样。** 不做数值采样、不用 SVD 求数值零空间，矩阵秩与零空间由
   SymPy 在有理函数域上精确计算。结果不受采样点选择与舍入误差影响。

4. **搜索与验证解耦、互为对照。** 搜索在 $u$ 坐标下完成；得到解后把 $K^{\mu\nu}$
   代回 $\theta$ 坐标，调用验证程序的 `poisson_cubic_coeffs` **独立重算** 20 个动量系数，
   逐个化简确认全为零。两条路径由不同代码实现，能暴露指标、符号与坐标替换的错误。

5. **解的规范化与自证。** 每个零空间向量按首个非零系数归一化后打印，同时输出对应的
   $Q$，方便人工识别「这是度规本身」还是「这是 Carter 张量」。

## 研究成果

### 1. 验证阶梯：4 个测试全部通过

`killing_tensor_verify_4d.py` 运行结果（精确符号运算）：

| 测试 | 守恒量 | 结果 | 耗时 |
| --- | --- | --- | ---: |
| (a) Minkowski | $K=\eta$，即 $Q=2H$ | 通过 | 0.08 s |
| (a) Minkowski | $L^2$ 张量 $r^4(\mathrm d\theta^2+\sin^2\theta\,\mathrm d\phi^2)$ | 通过 | 0.01 s |
| (b) Schwarzschild | $K=\mathrm dt\otimes\mathrm dt+\mathrm d\phi\otimes\mathrm d\phi$，即 $Q=p_t^2+p_\phi^2$ | 通过 | 0.43 s |
| (c) Kerr（Boyer–Lindquist） | Carter 张量（逆变标准形式） | 通过 | 2.03 s |

四个测试全部通过，**程序整体墙钟 4.4 秒**。

### 2. Kerr：从 Ansatz 重新解出 Carter 张量

取 5 个基张量

$$\left\{g^{\mu\nu},\ a^2\cos^2\theta\,g^{\mu\nu},\ a^2\cos^2\theta\,e_t\!\otimes\! e_t,\
e_\theta\!\otimes\! e_\theta,\ \cot^2\theta\,e_\phi\!\otimes\! e_\phi\right\},$$

搜索得到：

| 项目 | 数值 |
| --- | ---: |
| 基张量个数 | 5 |
| 独立方程个数 | 22 |
| 系数矩阵形状 | (22, 5) |
| 秩 | 3 |
| **解空间维数** | **2** |

两个解分别是：

- **解 0**：只有度规项，$Q=2H$（平凡解，符合预期）；
- **解 1**：$c=(0,1,1,-1,-1)$，即

  $$K^{\mu\nu}=a^2\cos^2\theta\,g^{\mu\nu}+a^2\cos^2\theta\,e_t\!\otimes\! e_t
  -e_\theta\!\otimes\! e_\theta-\cot^2\theta\,e_\phi\!\otimes\! e_\phi,$$

  这正是 **Carter 张量**。

两个解都由验证程序独立复核，$\{Q,H\}=0$ **均通过**。因此，程序把 Carter 张量**在给定的 5 维基张量空间里把它解了出来**——解空间恰好是
$\mathrm{span}\{\text{度规},\ \text{Carter}\}$，维数为 2，与理论预期一致。

### 3. Schwarzschild：解空间被完整刻画

取 5 个坐标基张量 $\{g^{\mu\nu},e_t\!\otimes\! e_t,e_r\!\otimes\! e_r,
e_\theta\!\otimes\! e_\theta,e_\phi\!\otimes\! e_\phi\}$：

| 项目 | 数值 |
| --- | ---: |
| 基张量个数 | 5 |
| 独立方程个数 | 3 |
| 系数矩阵形状 | (3, 5) |
| 秩 | 2 |
| **解空间维数** | **3** |

解空间由三项张成：

$$g^{\mu\nu}\ (Q=2H),
\qquad e_t\!\otimes\! e_t\ (Q=p_t^2),
\qquad e_\phi\!\otimes\! e_\phi\ (Q=p_\phi^2),$$

三者均通过独立复核，分别对应：**度规本身、时间平移对称性（能量）、
轴对称性（角动量）**，三者都是可约的二次守恒量。
这个结论与理论相符，也说明程序确实在做判断，而不是把所有输入都判为「通过」。

### 4. 性能

| 环节 | 耗时 |
| --- | ---: |
| 验证程序（4 个测试） | 4.4 s |
| 搜索：Kerr（矩阵组装 + 秩 + 零空间） | 0.51 s |
| 搜索：Schwarzschild | 0.04 s |
| 搜索程序整体墙钟 | 69.4 s |

搜索本身很快；**绝大部分时间花在解的规范化与符号复核**（对 $Q$ 做 `simplify`、
对 20 个系数逐个做三角化简），而不是线性代数。这说明瓶颈在化简，而不在求解。

### 结论的准确表述

本阶段得到的是：

- **验证层面**：工具在平直、Schwarzschild、Kerr 三类四维时空（含 Lorentz 度量与
  球坐标）上，对已知的二次守恒量给出精确的 $\{Q,H\}=0$ 确认。
- **搜索层面**：在**指定的**基张量空间内，Kerr 的 Carter 张量与 Schwarzschild 的
  $p_t^2,p_\phi^2$ 都被重新解出，且解空间维数与理论预期一致。

## 运行方式

两个脚本需放在同一目录：

```bash
python killing_tensor_verify_4d.py
python killing_tensor_search_4d.py
```

依赖：Python 3 与 SymPy。本机环境为 Python 3.13.3 + SymPy 1.14.0。
