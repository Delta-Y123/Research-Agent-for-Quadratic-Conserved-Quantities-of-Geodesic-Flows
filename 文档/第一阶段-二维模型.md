# 二维模型：研究内容、编程特点与研究成果

> 本节可直接用作仓库 README 的「第一阶段」章节。

## 研究内容

第一阶段的目标是**用一个具体的二维模型把「搜索—验证—分类」的完整流程跑通**，为后续的
Schwarzschild / Kerr 基准与一阶扰动分析提供可靠的确定性工具。

研究对象是共形平坦度量族

$$g_\varepsilon=\lambda_\varepsilon(x,y)\left(\mathrm dx^2+\mathrm dy^2\right),
\qquad
\lambda_\varepsilon=1+x^2+2y^2+\varepsilon x^2y^2,$$

在研究区域上要求 $\lambda_\varepsilon>0$。当 $\varepsilon=0$ 时，这是可分离的 **Liouville 型模型**，
具有一个已知的二次守恒量

$$Q_0=\frac{2y^2p_x^2-(1+x^2)p_y^2}{1+x^2+2y^2}.$$

核心问题是：

> **加入 $\varepsilon x^2y^2$ 之后，能否找到延续 $Q_0$ 的二次守恒量？**

搜索在有限维函数空间中进行：取

$$Q=\frac{A(x,y)p_x^2+B(x,y)p_xp_y+C(x,y)p_y^2}{\lambda_\varepsilon(x,y)},$$

其中 $A,B,C$ 是次数不超过 $d$ 的二元多项式。未知函数随之化为有限个未知系数，守恒条件
$\{Q,H\}=0$ 给出齐次线性系统

$$M(\varepsilon)\,\mathbf c=0 .$$

度量固定后该方程对 $K$ 是线性的，因此困难在**未知函数形式、方程规模与结论的完整性**，
而不在于求解一般非线性 PDE。

## 编程特点

程序为单文件 SymPy 脚本 `程序/二维/killing_tensor_search.py`（另附注释精简版
`killing_tensor_search_clean.py`，两者输出逐字节一致）。几个关键设计：

1. **免分母的三次齐次化。** 直接对 $Q=\widetilde Q/\lambda$ 计算 $\{Q,H\}$ 会残留 $1/\lambda$，
   无法按动量的三次单项式提系数。程序改用

   $$G:=\lambda\{\widetilde Q,K\}-K\{\widetilde Q,\lambda\}-\widetilde Q\{\lambda,K\},
   \qquad K=p_x^2+p_y^2,$$

   由莱布尼茨展开可证 $G=2\lambda^3\{Q,H\}$，于是 $G$ 是动量的**齐次三次多项式**且
   $\{Q,H\}=0\iff G=0$。整个推导过程中不出现任何分母，提系数干净且快。

2. **精确有理数运算。** $\varepsilon$ 以 `Rational` / 整数代入，矩阵秩由 SymPy 在有理数域上
   精确计算。因此「秩 = 16」是代数事实，而不是带浮点误差的数值估计。

3. **符号方程只建一次，参数按需代入。** 线性方程组先以符号 $\varepsilon$ 建立，再对每个
   $\varepsilon$ 取值组装系数矩阵。**代入发生在求解之前，因此不存在"除以 $\varepsilon$"
   而丢掉 $\varepsilon=0$ 分支的风险**——这正是后续 Agent 需要作为一等公民管理的异常分支，
   在第一阶段就已经从实现上规避。

4. **两条独立验证路线。** 求解走 Hamiltonian 表述 $\{Q,H\}=0$；解出后把 $Q$ 回代、用
   `simplify` 精确验证并 `assert` 残差为零。几何表述 $\nabla_{(i}K_{jk)}=0$ 作为第二条
   互校路线留待四维阶段接入。

5. **结果自证。** 程序不只打印秩与维数，还打印解空间的一组基、对应的 $A,B,C$ 与显式的 $Q$，
   使每个结论都能被人工复核。

## 研究成果

### 1. 解空间随扰动参数的退化（$d=2,4,6$）

在精确有理数运算下，把多项式次数提高到 $d=6$：

| 最高次数 $d$ | 单项式基 | 未知系数 | 方程数 | 秩（$\varepsilon=0$） | 解空间维数 | 秩（$\varepsilon\neq0$） | 解空间维数 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 6 | 18 | 64 | 16 | **2** | 17 | 1 |
| 4 | 15 | 45 | 124 | 43 | **2** | 44 | 1 |
| 6 | 28 | 84 | 200 | 82 | **2** | 83 | 1 |

结论在三个次数下**完全稳定**：$\varepsilon=0$ 时解空间维数为 2（由 $H$ 与 $Q_0$ 张成），
而 $\varepsilon\neq0$ 时降为 1（只剩 $H$ 的倍数）。**扩大候选空间并没有带回新的解。**

$\varepsilon=0$ 时的两个基向量为

$$Q^{(0)}=\frac{p_x^2+p_y^2}{\lambda_0}=2H,
\qquad
Q^{(1)}=\frac{-(1+2y^2)p_x^2+x^2p_y^2}{\lambda_0}
=-Q_0-2H .$$

第二式与规划中写下的 $Q_0$ 只相差 $H$ 的倍数，属于同一解空间，可互为校验。

### 2. 参数扫描：$\varepsilon=0$ 是唯一的降秩点

针对规划中提出的开放问题「除了 $\varepsilon=0$，还有没有特殊参数使矩阵降秩」，
在

$$\varepsilon\in\left\{0,\pm\tfrac14,\pm\tfrac12,\pm1,\pm2,\pm4,\pm5,\pm8,\pm10,\pm16,
\tfrac13,\tfrac23,-\tfrac23,\pm\tfrac32,\tfrac18\right\}$$

共 24 个取值上扫描：$d=2$ 与 $d=4$ 的全部取值中，**只有 $\varepsilon=0$ 使矩阵降秩**，
其余一律为满秩减一（解空间维数 1）。即在这一扫描范围内，$\varepsilon=0$ 是唯一的特殊参数。

### 3. 解的符号验证

$\varepsilon=0$ 时解空间的两个基向量均通过精确符号验证：$\{Q,H\}=0$ 化简结果为零，
程序内置的断言未触发。

### 结论的准确表述

上述结果的严格含义是：**在次数不超过 $d$（$d=2,4,6$）的多项式系数空间内，
$\varepsilon=0$ 处可分离的守恒量 $Q_0$ 不能延续到 $\varepsilon\neq0$，且没有出现新的二次守恒量。**

它**不是**「扰动后不存在任何额外 Killing 张量」的证明——换个函数基底、换一组坐标或改变
分母的形式，都可能改变结论。按项目约定的状态词，这属于「**限定空间内无额外解**」，
所有结论都必须与搜索空间一同陈述。

### 当前边界与下一步

- 已做：$d\le6$ 的多项式候选空间、24 个参数取值的降秩扫描、$\varepsilon=0$ 解的符号回代验证。
- 待做：$d=8$ 及更高次数的确认；更换基底与坐标的交叉检查；把结果转回 $K_{ij}$ 并检验
  $\nabla_{(i}K_{jk)}=0$；与二维局部分类文献（Bolsinov–Matveev–Pucacco，
  arXiv:0803.0289）的已知结论对照，判断这里的现象是否已被理论覆盖。

## 运行方式

```bash
python 程序/二维/killing_tensor_search.py
# 交互输入：最高次数 d（回车默认 2）
#           epsilon 列表，逗号分隔（回车默认 0, 1, -0.25）

# 非交互（管道喂入空输入即取默认值）
printf '\n\n' | python 程序/二维/killing_tensor_search.py

# 指定 d = 6
printf '6\n\n' | python 程序/二维/killing_tensor_search.py

# 指定参数点
printf '4\n0,1,-1/4,1/2\n' | python 程序/二维/killing_tensor_search.py
```

依赖：Python 3 与 SymPy（`pip install sympy`）。本机实测耗时：$d=2$ 约 2 秒，
$d=4$ 约 14 秒，$d=6$ 约 40 秒。
