# 面向测地流二次守恒量的研究 Agent (Research-Agent-for-Quadratic-Conserved-Quantities-of-Geodesic-Flows)

## Killing 张量搜索、符号验证与扰动分析 (Killing Tensor Search, Symbolic Verification, and Perturbation Analysis) 

本项目是“人工智能与数学”课程的研究作业，旨在结合微分几何、Hamilton 力学与符号计算，构建一个辅助搜索和验证 Killing 张量的研究 Agent。项目将从简单的二维度量出发，逐步过渡到广义相对论中的经典时空，并探索度量扰动对测地流守恒量的影响。本仓库将持续记录数学推导、程序开发、计算实验与阶段性结论。

## 核心问题

**当一个度量受到扰动时，它原有的二次测地流守恒量能否继续存在？如果不能，延续的阻碍出现在哪里？**

对于给定度量 $g$，测地流的 Hamiltonian 为

$$
H=\frac12 g^{ij}p_ip_j.
$$

本项目寻找关于动量的二次齐次守恒量

$$
Q=K^{ij}(x)p_ip_j,
$$

使其满足泊松括号条件$`\{Q, H\} = 0`$.

这一条件等价于相应对称张量满足 Killing 张量方程。研究将围绕以下问题展开：

- 如何在给定的候选函数空间中，自动搜索并精确验证二次守恒量？
- 如何识别由度量和已知 Killing 向量生成的可约解？
- 当度量随参数变化时，候选解空间的维数是否发生变化？
- 已知守恒量能否通过一阶修正延续到扰动后的度量？

## 研究路径

### 第一阶段：二维模型与基础工具

从具有已知二次守恒量的二维可分离度量入手，推导守恒条件，建立“输入度量—生成候选量—构造方程—求解—回代验证”的完整流程。

在此基础上加入简单的参数扰动，比较不同参数与候选函数空间下的解，形成首批可重复运行的计算实验。

第一阶段的成果见 [文档/第一阶段-二维模型.md](文档/第一阶段-二维模型.md)：包含研究内容、程序设计与实现特点，以及 $d=2,4,6$ 的搜索结果与参数扫描。

### 第二阶段：经典时空中的守恒量验证

将工具逐步应用于平直时空、Schwarzschild 时空和 Kerr 时空，验证能量、角动量及 Carter 常数等已知守恒量，并检查程序对 Lorentz 度量和不同坐标表达的适用性。

这一阶段以复现和验证为主，同时完善可约性检查与计算结果记录机制。

### 第三阶段：一阶扰动与守恒量延续

考虑展开

$$
H_\varepsilon=H_0+\varepsilon H_1+O(\varepsilon^2),
\qquad
Q_\varepsilon=Q_0+\varepsilon Q_1+O(\varepsilon^2).
$$

在已知 $`\{Q_0,H_0\}=0`$ 的基础上，研究一阶方程$`\{Q_1,H_0\}=-\{Q_0,H_1\}.`$

通过限定扰动族与候选系数空间，尝试找出允许守恒量延续的参数条件，或给出该搜索范围内的不相容证据。

### 第四阶段：Agent 决策与效果评估

让 Agent 根据计算结果选择下一项实验，例如扩大候选基底、检查特殊参数、利用对称性化简或调整计算规模。

将其与固定搜索流程进行比较，考察 Agent 能否减少无效计算、发现值得进一步分析的参数，并生成准确、可核验的研究记录。

## 方法与定位

项目采用“大模型决策 + 确定性数学工具 + 人工审查”的工作方式：

- **Agent：**提出计算方案、选择参数与候选形式、调用工具，并根据结果调整下一步实验。
- **数学工具：**完成符号微分、泊松括号计算、线性方程求解及精确回代验证。
- **研究者：**确定问题与适用范围，完成关键推导，审查结论并判断其研究意义。

计算中将通过提取泊松括号的动量系数，把守恒条件转化为方程组；在有限候选空间下，进一步转化为关于未知系数的线性系统。所得候选量需回代原方程，并尽可能通过 Killing 张量方程进行交叉检查。

项目将明确记录结论的适用范围：**在指定候选空间中没有找到额外解，不代表已经证明所有 Killing 张量均不存在。** 数值测地线实验用于展示守恒行为和检验误差，数学结论则以符号验证或明确的证明为依据。

学期内的主要目标是建立可信、可复现的搜索与验证工具，并完成一个有限研究范围内的参数分析或扰动结果。仓库将同步保存成功算例、失败尝试与计算限制，供课程汇报和后续研究使用。

## 技术栈

项目初期拟采用以下技术，随开发进展逐步完善：

| 技术 | 主要用途 |
|---|---|
| Python | 组织数学计算、工具接口与实验流程 |
| SymPy | 符号微分、泊松括号、线性求解和恒等式验证 |
| NumPy / SciPy | 测地线数值积分与误差分析 |
| Matplotlib | 展示测地线轨迹、守恒量漂移和参数实验结果 |
| Jupyter Notebook | 记录数学推导与交互式计算实验 |
| 支持工具调用的大模型 API | 构建 Agent 的实验选择与结果分析循环 |
| Git / GitHub | 管理代码版本、开发任务和阶段性研究记录 |

初期采用单 Agent 架构，通过调用已有符号计算与数值工具完成任务，无需自行训练模型。
