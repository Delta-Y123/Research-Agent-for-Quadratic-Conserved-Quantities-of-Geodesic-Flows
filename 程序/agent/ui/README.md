# 研究 Agent 前端界面

单文件 HTML + Python 标准库后端（`http.server` + SSE），**零框架依赖**。
数学公式用本地 KaTeX 渲染，离线可用。

> ## ⚠️ 不要双击 `index.html`
>
> 直接双击打开时地址是 `file://`，页面里的 `/api/...` 会变成 `file:///api/...`，
> 浏览器会拒绝，界面只会显示一个引导遮罩。
>
> **浏览器里跑不了这个系统**：Kerr 一阶分类一次要做约 130 秒的精确有理数
> 线性代数（Pyodide 跑 SymPy 会慢一到两个数量级），模拟器又是 C++/CUDA 原生程序。
> 所以架构必然是「浏览器看 + Python 算」。
>
> 正确用法二选一：
>
> **① 双击项目根目录的 [`启动研究界面.bat`](../../启动研究界面.bat)**（或
> [`程序\agent\启动界面.bat`](../启动界面.bat)）—— 自动起服务并打开浏览器。
> 这两个 `.bat` 是**纯 ASCII** 的：含中文路径的批处理会被 cmd 按当时的代码页
> 解码成乱码，所以它们改用 `%~dp0` 和递归搜索 `ui\server.py` 来定位目录。
>
> **② 手动**：
>
> ```powershell
> cd "…\程序\agent"
> python ui/server.py --port 8765 --open
> ```
>
> 然后访问 `http://127.0.0.1:8765/`。服务窗口关掉，页面就失效。

## 1. 界面分区

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏：状态灯（模拟器 / 密钥 / 模型 / 步数 / 耗时）+ 问题输入 + 运行控制 │
├───────────────┬──────────────────────────────┬───────────────────────┤
│ 实验时间线     │ 结论（KaTeX 渲染）            │ 黑洞模拟器控制面板     │
│ · 每步工具     │ · 每条带 status / 证据 / 范围 │ · 预设 / a / r₀ / θ₀   │
│ · 诊断色条     │                              │                       │
│ · 关键数字     │ 策略守门（打回 / 通过）        │ 候选 Q 漂移（对数纵轴） │
│ · 可展开原始   │                              │                       │
│               │ 研究报告（markdown）          │ 观察者成像（CUDA）     │
├───────────────┴──────────────────────────────┴───────────────────────┤
│ 台账：每次工具调用的判定与耗时                                         │
└──────────────────────────────────────────────────────────────────────┘
```

**诊断色编码**（时间线左侧竖条与判定徽章）：

| 颜色 | kind | 含义 |
|---|---|---|
| 绿 | `existence` | 找到了超出已知不变量的解 / 数值上守恒 |
| 琥珀 | `nonexistence_in_span` | 声明的候选空间内没有额外解 |
| 蓝 | `classification` | 分类结论（允许/排除） |
| 红 | `artifact` | 网格伪解，需要加密重算 |
| 灰 | `inconclusive` | 证据不足 |

## 2. 演示参数

URL 参数可以直接把界面拉到一个演示状态，方便课堂投影或截图：

| 参数 | 作用 |
|---|---|
| `q=<问题>` | 预填问题 |
| `mode=llm\|rules` | 选择规划模式 |
| `steps=6` `budget=900` | 覆盖步数与预算 |
| `auto=1` | 自动点「开始研究」 |
| `sim=1` | 自动触发一次候选 Q 漂移监测 |
| `render=1` | 自动渲染一张黑洞图像 |
| `preset=kerr_inclined` | 预选模拟器预设 |

例：

```
http://127.0.0.1:8765/?mode=rules&steps=6&sim=1&render=1&auto=1
  &q=Kerr 的 Carter 常数在破坏式(54)配合关系的扰动下还能延续吗？
```

## 3. 候选 Q 漂移图

纵轴是 $\log_{10}|\Delta Q/Q|$，横轴是仿射参数 $\lambda$。图上同时画三条：

* **Carter Q**（符号层的 $K^{\mu\nu}$）——应当压在 $10^{-10}$ 附近；
* **H**——应当压在 $10^{-16}$ 附近；
* **Q 系数 ×1.05**（故意写错的候选）——应当单调爬到 $10^{-2}$。

这张图是界面里最重要的东西：它让"符号上守恒"和"数值上不漂移"**用同一个
$K^{\mu\nu}$** 同时可见。如果正确候选不贴底、或错误候选不上升，说明链路有问题。

## 4. 与模拟器的接口

后端通过 `simulator.py` 调用 `D:\For Spacetime Simulator\dist\bh_cli.exe`：

| 用途 | 命令 |
|---|---|
| 列预设 | `bh_cli --list-presets` |
| 积分轨迹 | `bh_cli [--preset X \| --scene s.json] --no-render --trace t.json` |
| 渲染图像 | `bh_cli [--preset X \| --scene s.json] --width W --height H --out p.png` |

`--scene` / `--trace` 是本次为接入 Agent 而新增的（原来只能跑内置预设、
只出图不吐数据）。轨迹 JSON 里带 Boyer–Lindquist 坐标与协变动量，
所以外部可以直接算 $Q=K^{\mu\nu}p_\mu p_\nu$，不必在 C++ 里重写候选量。

用 `BH_SIM_ROOT` 环境变量可以指向别的安装目录；找不到时界面自动降级
（模拟器面板变灰，其余功能正常）。

## 5. 静态资源

`vendor/katex/` 是从 CDN 拉下来的一份 KaTeX（约 560 KB，含 20 个 woff2 字体），
所以断网也能正确排版公式。需要更新时：

```
python ui/fetch_katex.py
```

## 6. 排错

* **界面显示"模拟器 缺失"**：`dist\bh_cli.exe` 不在默认路径。设 `BH_SIM_ROOT`
  或重新构建模拟器。
* **渲染 503 `save failed`**：旧版 `bh_cli.exe` 用 ANSI 解码命令行，中文路径会
  失败。用 2026-11-03 之后构建的版本（已改用 Qt 宽字符参数）。
* **LLM 模式报"服务进程没有 MIMO_API_KEY"**：密钥要在**启动服务之前**设进环境变量。
* **SSE 卡住不动**：反向代理会缓冲 `text/event-stream`；本机直连不受影响。
